### Blog Web Application - Frontend
A simple frontend web application for a blogging platform where users can read and comment on articles, and authors can create and manage their own posts.

### Features
1.User Features

2.View all published articles

3.Read full article details

4.Comment on articles

5.View author profiles

6.User profile page showing all published articles

7.Author Features

8.Create new articles

9.Edit or delete own articles

10.View all authored articles
