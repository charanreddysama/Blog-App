### Backend development

1. Create git repo
     git init
2. Add .gitignore file

3. Create .env file for the environment variables  and read data from .env with "dotenv" module

4. generate package.json
   npm init -y

5. install express
   npm install express

6. connect to database
   npm install mongoose 
   
7. add middleware (body parser,err handling middleware)

8. design schemas and create models
